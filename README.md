conf_name: parsed conference name.

conf_place: parsed conference place.

conf_dates: human-readable date span.

conf_start_date: machine-friendly start date.

conf_end_date: machine-friendly end date.

conf_code: placeholder for conference-series code.

conf_order: edition/order number.

conf_concat: display string combining name, place, and dates.

note: parser note or explanation.
